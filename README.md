EmberChess: a 4 KB Python chess engine — 0x88 board, alpha-beta + transposition table + null-move pruning + LMR + quiescence, tapered PST eval. Practice Elo ~1,456 on the kit gauntlet (threshold 1,154), beating sunfish's 4 KB baseline.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
